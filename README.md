## Overview

SECOND BRAIN is a collaborative knowledge-sharing platform designed to make academic learning more organized, accessible, and efficient for college students.

It provides a centralized space where students can share educational resources, discover useful information, and benefit from collective knowledge.

Our goal is simple: make valuable knowledge easier to preserve, discover, and share.

## The Problem

Students often face challenges such as:

- Academic resources scattered across multiple platforms.
- Difficulty finding relevant notes and study materials.
- Repeated questions and duplicated efforts.
- Valuable academic knowledge getting lost.
- Limited opportunities for collaborative learning.

## Our Solution

SECOND BRAIN brings student knowledge into one organized digital platform.

It aims to simplify how students access, manage, and share academic resources while encouraging a culture of collaborative learning.

## Key Features

- **Knowledge Sharing:** A common space for sharing academic resources.
- **Resource Discovery:** Find useful learning materials.
- **Organized Learning:** Keep educational information structured.
- **Student Collaboration:** Encourage peer-to-peer knowledge exchange.
- **Accessible Interface:** A student-friendly interface for everyday use.

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/vanshgoswami-hack/second-brain-ai.git
```

**2. Navigate to the project directory**

```bash
cd second-brain-ai
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

If required, create a local `.env` file using `.env.example` and configure the necessary values.

Never commit private credentials or API keys.

**5. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal.
